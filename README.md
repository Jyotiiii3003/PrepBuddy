# PrepBuddy

AI-powered platform for Data Structures & Algorithms (DSA) and Aptitude preparation, designed to help students and job aspirants prepare effectively for coding interviews and placement tests.

---

## Overview

PrepBuddy is an intelligent preparation platform focused on improving interview readiness through structured DSA practice, aptitude problem solving, and AI-driven guidance.

The platform aims to simplify preparation by providing a clean, interactive, and user-friendly experience where learners can practice consistently and receive smart recommendations based on their learning journey.

---

## Features

### DSA Practice
- Solve Data Structures and Algorithms problems
- Strengthen problem-solving and coding skills
- Practice interview-focused questions

### Aptitude Preparation
- Quantitative aptitude questions
- Logical reasoning practice
- Placement and competitive exam preparation support

### AI-Powered Recommendations
- Smart suggestions based on user activity
- Personalized preparation guidance
- Improved learning experience through AI assistance

### Modern User Experience
- Clean and responsive interface
- Smooth animations using Framer Motion
- Fast performance with Vite

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm or YARN

---

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/prepbuddy.git
```

Navigate to the project folder:

```bash
cd prepbuddy
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The application will start locally.

---

## Available Scripts

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
